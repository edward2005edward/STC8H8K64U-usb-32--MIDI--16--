# USB MIDI-контроллер и клавиатура на базе STC8H8K64U

Высокопроизводительный аппаратный usb 32-клавишный MIDI-контроллер и 16-канальный аналоговый 
микшер на базе микроконтроллера **STC8H8K64U** (в корпусе TSSOP20). частота 24мгц
Проект полностью разработан в операционной системе Linux Mint с использованием бесплатного компилятора **SDCC**.

## 🚀 Основные особенности

* **32-клавишная музыкальная матрица:** Построена на каскаде из четырех сдвиговых регистров `74HC165`. 
Опрос выполняется на сверхбыстром, вручную оптимизированном ассемблерном сканере.
если вы хотите умешить количество кнопок тогда пин 9 у последнего регистра надо подтянуть к +5в через 10ком
если вообще только аналоговый контроллер то пин 19 STC8H8K64U надо подтянуть к +5в через 10ком

* **Пакетный залп аккордов без задержек:** Одновременно нажатые музыкантом клавиши (но не более 16)
упаковываются процессором в один общий USB-кадр. 
Это обеспечивает нулевой джиттер и мгновенный отклик в секвенсорах (например, в LMMS).
* **16-канальный аналоговый мультиплексор:** Микросхема `CD4067` опрашивает до 16 потенциометров. 
Реализован двойной программный фильтр (фиктивное Dummy-преобразование для сброса заряда + 16-кратный оверсэмплинг), 
что даёт тишину АЦП без прыжков значений.

* **Динамические контроллеры:** Реализована плавная регулировка 
громкости нажатия клавиш (`Velocity`) с помощью аналоговой ручки, 
а также колесо Pitch Bend с аппаратной мертвой зоной по центру. ( индикатор Р1.4 )
* **Аппаратный сдвиг октав:** Выделенные тактовые кнопки на пинах `P3.2` и `P3.3` ( индикатор Р1.5 )
(подтянутые внешними резисторами 10..47 кОм к +5В) 
позволяют смещать диапазон нот вверх и вниз на целую октаву.

* **Функции типа `__naked` (Голые функции):** Критичные ко времени выполнения функции используют атрибут `__naked`, 
полностью исключая служебный Си-пролог и эпилог компилятора. 
Результат сканирования кнопок заносится напрямую в аппаратные регистры процессора STC8H8K64U (`DPL`, `DPH`, `B`, `A`).


## 🔌 Особенности аппаратной схемы

*(Полная принципиальная схема устройства прикреплена к файлам репозитория)*

* **Защита от импульсных помех USB:** Питание аналогового мультиплексора `CD4067` и всех 
потенциометров изолировано от шумной шины `USB +5V` 
с помощью диода `1N4148` (или любого шотки ) и каскада фильтрации из электролита на 470 мкФ и керамики 0.1 мкФ. 
Шум от обмена USB-пакетами и пульсаций по питанию физически не долетает до АЦП.

* **Гибридная совмещенная шина:** Адресные линии `P3.6` и `P3.7` используются одновременно для переключения 
каналов `CD4067` и тактирования/защёлки `74HC165`. 
Это позволило уместить огромный инструмент в 20-пиновый корпус TSSOP20.


### Инструменты для сборки:
* Операционная система Linux (например, Linux Mint).
* Компилятор `sdcc` (ANSI-C компилятор для MCS51).

* Программатор `stcprog` (или `stc8prog`) для быстрой заливки через терминал.
код взят отсюда https://github.com/IOsetting/stc8prog был скомпилирова 
из исходного на Debian 9/32bit на Linux Mint 21 64 бит работает.
